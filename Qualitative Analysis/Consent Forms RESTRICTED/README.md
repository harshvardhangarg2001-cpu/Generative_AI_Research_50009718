# Consent Forms - RESTRICTED

Signed participant consent forms carry names and signatures, so they are
**never committed to this repository**. They are stored in UQ Research Data
Manager (RDM) with access limited to the investigators named on the ethics
approval.

Only de-identified material derived from participants appears in this repo.
Participants are referred to as P01, P02, ... throughout; the mapping from those
codes back to real identities is held in RDM, not here.
